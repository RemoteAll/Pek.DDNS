# 项目接续指南（换电脑 / 新会话 必读）

> 目的：让任何一台电脑上的 Copilot（或人员）快速无损接续本项目。
> 维护：每轮大改后由 Copilot 更新；配套 `docs/项目记忆.md`（AI 记忆镜像）同修。
> 最近更新：2026-10-10（接续基建；Rust.DDNS 部署与一键打包脚本）
> ⚠️ 本目录**随仓库版本管理**（2026-10-10 起入库）：新电脑 `git clone/pull` 后即可直接阅读本指南与配套台账。

## 0. 一句话

Pek.DDNS＝DDNS 动态域名解析工具集（单 git 仓库、4 个子工程）：**Zig.DDNS**（Zig 主工具，Zig ≥ 0.17）、**Hlk.FixHosts**（Zig hosts 工具）、**Rust.DDNS**、**Rust.FixHosts**。远程：`github.com/RemoteAll/Pek.DDNS`（**公开仓库**）。

## 1. 新电脑三步接续

1. `git clone https://github.com/RemoteAll/Pek.DDNS.git` → VS Code 打开 → 登录 Copilot。
2. 新会话第一句（可复制）：
   > 先读 `.github/copilot-instructions.md`、`docs/项目接续指南.md`、`docs/用户档案.md`、`docs/项目记忆.md`，再汇报当前状态与待办。
   （注：`docs/` 台账随仓库走——`git clone/pull` 后直接可用；若仍缺，恢复本目录即可。）
3. 环境验证：
   - Zig ≥ 0.17（本机路径：`E:\Soft\zig-x86_64-windows-0.17.0\zig-x86_64-windows-0.17.0\zig.exe`）
   - `cd Zig.DDNS` → `zig build` → `zig build test` （基线：全绿）
   - `cd Hlk.FixHosts` → `zig build` （基线：全绿；产物带 require_admin 清单）
   - Rust 子工程：各自独立 `cargo build`（无组织通用库依赖）

## 2. 关键约束（坑）

- zzig 依赖 = `https://github.com/PeiKeSmart/zzig/archive/374fd60eb0059e99f2b4959d72d80f668365bf01.tar.gz`（URL+hash 模式）——**禁止改回 path 依赖**（main 提交历史明确要求）。
- Zig 0.17 `build.zig.zon` 必填：`fingerprint` + 顶层 `.paths`（错误 fingerprint 会被拒绝并提示正确值，照提示补即可）。
- 分支：`dev` / `main`（**无 master**）；**远程名也叫 `main`**（refname 有歧义警告，脚本里用 `refs/heads/main` 消歧）。
- 敏感文件：Zig.DDNS 的 `local.secret.zig` / `config.json` **不要提交、不要输出**（`.gitignore` 已含 `Zig.DDNS/config.json`）。
- Hlk.FixHosts 写 hosts 需管理员权限（build.zig 生成 require_admin.manifest）；Windows API 为自 `extern` 声明（0.17 已移除 kernel32 封装）。
- 本机 GitHub 直连受 hosts 劫持影响时，推送用：`git -c http.curloptResolve=github.com:443:<真实IP> push …`（IP 用 `Resolve-DnsName github.com -Server 223.5.5.5` 获取；参考值 20.205.243.166）。

## 4. 工作惯例（此项目怎么协作）

- 每轮流程：改动 → `zig build` / `zig build test` 回归 → 决策记录新增一节（**含用户原话**）→ 同步 `docs/项目记忆.md`。
- 规范：遵循用户级接续协议（`%APPDATA%\Code\User\prompts\跨项目接续协议.instructions.md`）+ 本仓库 `.github/copilot-instructions.md`（Zig 0.17 兼容规范、提交消息模板、禁止项等）。
- **台账口径**：`docs/` 随仓库走（2026-10-10 定案，见决策记录 §4）；本仓库为公开仓库，归档内容即公开可见——写入前请自行斟酌。

## 5. 跨电脑同步方案

- **代码**：git 远程（`github.com/RemoteAll/Pek.DDNS`，公开）。
- **用户级指令**：零复制模式——本机已装（版本 2026.10.08.1）。其他电脑两条路：① Settings Sync 勾选 "Prompts and Instructions" 自动漫游；② 打开任一已装备仓库（串口屏 / DH.RustBase / 本项目）即自动自检补装。
- **本台账（`docs/`）**：随仓库走（2026-10-10 定案）——跨机器由 `git clone/pull` 直达；因仓库公开，内容即公开可见。
- **新电脑首次接续（防覆盖）**：先按 §1 读 `docs/项目记忆.md`；**首次回灌前**，把镜像中的历史并入本机 repo 记忆后再跑 `sync-memory.ps1`——避免稀疏的本机记忆覆盖完整镜像（镜像已入 git，误覆盖亦可在提交历史中找回）。
- **自检自愈**：本项目已含 `tools/continuity/` + `.vscode/tasks.json`（打开项目自动运行自检，首次需点「允许自动任务」）。

## 6. 常用命令

- Zig.DDNS 构建 / 测试：`cd Zig.DDNS` → `zig build` ／ `zig build test`
- Zig.DDNS 发版打包（UPX）：`.\Zig.DDNS\pack_upx.ps1`
- Hlk.FixHosts 构建：`cd Hlk.FixHosts` → `zig build`（写 hosts 时以管理员运行）
- Rust 子工程：`cd Rust.DDNS` → `cargo build` ／ `cd Rust.FixHosts` → `cargo build`
- Rust.DDNS 部署到星尘：`sudo sh Rust.DDNS/deploy/install.sh [目录]`（`--unregister` 注销；配置在安装目录 `config.json`）
- Rust.DDNS 一键打包：`powershell -ExecutionPolicy Bypass -File Rust.DDNS\scripts\build-release.ps1`（产物在 `dist\`，包内含 install.sh）
- 接续自检手动运行：`powershell -ExecutionPolicy Bypass -File tools\continuity\install-global-instruction.ps1`
- 记忆回灌：`powershell -ExecutionPolicy Bypass -File <已装备仓库>\tools\continuity\sync-memory.ps1 -ProjectPath <本项目路径>`
